# 🤖 CYBER-DEGEN 3000 // Memecoin AI Robot Terminal

Ένα φουτουριστικό **Cyberpunk AI Trading Dashboard** με διαδραστικό **3D Ρομπότ** (Three.js WebGL) και **ρομποτική φωνή** (Text-to-Speech) ειδικά σχεδιασμένο για **Memecoins** και **TikTok / Livestreams**!

---

## ⚡ Χαρακτηριστικά

### 1. 🤖 3D Cyber-Mech Avatar (Three.js WebGL)
* **3D Ρομποτικό Κεφάλι:** Φουτουριστικό cranium από τιτάνιο, LED visor, κεραίες και περιστρεφόμενα ολογραφικά δαχτυλίδια.
* **Eye-Tracking:** Ακολουθεί ομαλά τον κέρσορα του ποντικιού στην οθόνη.
* **Δυναμικά States:**
  * 🟢 **PUMP MODE:** Πράσινα **Laser Eyes** που εκτοξεύονται προς την κάμερα, έντονο ενεργειακό vibration, confetti και ήχος νίκης!
  * 🔴 **DUMP / RUG ALERT:** Κόκκινος συναγερμός που αναβοσβήνει, cyber σειρήνες και προειδοποίηση.
  * 🟣 **NEURAL SCANNING / SPEAKING:** Κυανό-μοβ scanlines και κινούμενα equaliser bars στο στόμα καθώς μιλάει.

### 2. 🧠 AI Market Analyzer & Ρομποτική Φωνή (TTS)
* Πατήστε **«EXECUTE NEURAL SCAN»** σε οποιοδήποτε νόμισμα:
  * Το ρομπότ ενεργοποιείται, κάνει ανάλυση και **μιλάει ζωντανά με ρομποτική φωνή**!
  * Υποστηρίζει **Ελληνικά (🇬🇷 ΕΛ)** και **Αγγλικά Degen Trading (🇺🇸 EN)**.
  * Εμφανίζει AI Verdict (π.χ. `🚀 FULL DEGEN APE`, `⏳ HODL & CHILL`, `🎯 STEADY ACCUMULATION`).
  * Δείκτες: RSI (14), 24h Volume, Market Cap, Whale Inflow/Outflow radar.

### 3. 🐕 Live Memecoin Radar
* Ζωντανές τιμές και ποσοστά (με live Binance WebSocket):
  * **PEPE** (Pepe the Frog)
  * **DOGE** (Dogecoin)
  * **WIF** (dogwifhat)
  * **SHIB** (Shiba Inu)
  * **BONK** (Bonk)
  * **POPCAT** (Popcat)
  * **FLOKI** (Floki Inu)
  * **BRETT** (Brett - Base Chain)
* Διαδραστικό Canvas Chart σε πραγματικό χρόνο.

### 4. 📱 TikTok / Streamer Mode
* Κουμπί **«TIKTOK MODE»** στο header για βελτιστοποιημένη κινηματογραφική προβολή (ιδανικό για OBS, screen recording ή TikTok Live).
* Κουμπιά **PUMP** & **RUG** για άμεση ενεργοποίηση των viral εφέ μπροστά στο κοινό!
* Ηχητικά εφέ: Laser beams, cash chimes, σειρήνες συναγερμού (με κουμπί Mute).

## 🚀 Πώς να το τρέξετε

### Επιλογή 1 (Ένα κλικ):
Κάντε διπλό κλικ στο αρχείο **`start.bat`** στο φάκελο του project. Θα ανοίξει αυτόματα ο browser στο:
👉 **`http://localhost:3000`**

### Επιλογή 2 (Μέσω Terminal):
```bash
node server.js
```

Και ανοίξτε το **`http://localhost:3000`** στον browser σας (Chrome / Edge / Brave / κλπ.)!
