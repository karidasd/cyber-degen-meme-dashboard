## ⚡ Key Features

### 1. 🤖 3D Humanoid Android Robot (Three.js WebGL)
* **Sculpted Android Mech Bust:** Contoured titanium cranium, carbon-fiber armor plating, chest Arc Reactor, and mechanical spine pistons.
* **Optical Camera Eye Tracking:** Dual-lens camera sensors smoothly track cursor movement in real time.
* **Articulated Mechanical Jaw:** The lower jaw realistically articulates and drops in sync with synthetic voice output!
* **Dynamic Reaction States:**
  * 🟢 **PUMP MODE:** Dual high-intensity volumetric **Laser Beams** ignite from optical pupils, triggering energetic vibration, confetti explosions, and victory cash chimes!
  * 🔴 **DUMP / RUG ALERT:** Red alarm klaxon lighting, hazard strobes, and emergency sirens.
  * 🟣 **NEURAL SCANNING / SPEAKING:** Glowing holographic scanlines and cybernetic audio visualizer bars.

### 2. 🗣️ AI Voice Broadcaster & 24/7 Streamer Mode (TTS)
* **Autonomous 24/7 Voice Streamer:** Toggle `AUTO-SPEECH [ON]` to enable continuous hands-free hosting every 25 seconds for TikTok & YouTube streams!
* **On-Demand Neural Briefing:** Click **`SPEAK ANALYSIS`** or **`ALL MEMES BRIEFING`** for instant voice breakdowns.
* **Multi-Language Engine:** Switchable on-the-fly between **🇺🇸 English (Degen/Quant slang)** and **🇬🇷 Greek**.
* **AI Personas:** Selectable commentary personas:
  * 🚀 **Based Chad:** Maximum hype, moon mission energy.
  * 📈 **Quant Analyst:** Statistical metrics, volume-to-liquidity ratios, order flow depth.
  * 🔥 **Degen Ape:** High-volatility breakout detection.

### 3. 📊 100% Real Live Market Data (Binance REST + WebSockets)
* Live real-time market ticks, 24h high/lows, and real volume streamed via Binance WebSocket:
  * **PEPE** (Pepe the Frog)
  * **DOGE** (Dogecoin)
  * **WIF** (dogwifhat on Solana)
  * **BONK** (Bonk on Solana)
  * **SHIB** (Shiba Inu on Ethereum)
  * **FLOKI** (Floki Inu on BNB/ETH)
  * **POPCAT** (Popcat on Solana)
  * **BRETT** (Brett on Base)
* Real-time Canvas Volatility Radar chart.

### 4. 🎥 Streamer & Creator Toolkit
* **🟢 OBS Green Screen Mode:** 1-click toggle turns the canvas into pure `#00ff00` Chroma Green. Perfect as an OBS Studio / TikTok Live Studio browser source to overlay the 3D robot over live charts!
* **🎵 Cyber Synth Ambient BGM:** Generative lo-fi synthwave ambient radio playing continuous royalty-free sci-fi background chords.
* **💬 Simulated TikTok Live Chat & Gifts:** Rolling live chat with simulated viewer comments and interactive `GIFT 🌌` donations that trigger robot celebrations.
* **🐋 Real-Time Whale Radar Ticker:** Live scrolling marquee tracking massive swaps, DEX inflows, and short/long liquidations.

## 🚀 Running Locally

### Option 1 (One Click - Windows):
Double-click `start.bat` in the project root. Your default browser will launch at:  
👉 `http://localhost:3000`

### Option 2 (Node.js Server):
```bash
node server.js
```

Or open `index.html` directly in any web browser!
